# bronto-community Scoop bucket

[![CI](https://github.com/bronto-community/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/bronto-community/scoop-bucket/actions/workflows/ci.yml)

[Scoop](https://scoop.sh) bucket for command-line tools published by the
[bronto-community](https://github.com/bronto-community) org. What each tool
works with is up to that tool. Some are specific to a vendor, some aren't.

| Manifest | What it is | Upstream |
| --- | --- | --- |
| `bronto` | Community CLI for the [Bronto](https://bronto.io) observability platform | [bronto-cli](https://github.com/bronto-community/bronto-cli) |

## Install

```pwsh
scoop bucket add bronto-community https://github.com/bronto-community/scoop-bucket
scoop install bronto-community/bronto
```

## Updating

```pwsh
scoop update
scoop update bronto
```

## Reporting problems

Report anything about the tools themselves on their own issue trackers, for
example [bronto-cli](https://github.com/bronto-community/bronto-cli/issues).
Open an issue **here** only for problems with the bucket itself, such as a
manifest that fails `scoop install` for a packaging reason.

## How this repo is maintained

The manifests are generated by [goreleaser](https://goreleaser.com/) from each
project's release pipeline and pushed here by a bot. **Manual edits to
`bucket/*.json` are overwritten by the next release.** Fix the `scoops:`
section in the upstream repo's `.goreleaser.yaml` instead.

Because goreleaser updates the manifests, this bucket has no Excavator
(`checkver`/`autoupdate`) workflow; two writers would race each other.

CI runs Scoop's bucket test suite (schema and file style), then installs every
manifest for real on amd64 and arm64 Windows runners and runs the installed
tool. On push, weekly, and on demand (Actions, CI, Run workflow) it follows the
install steps above exactly; on pull requests it installs the proposed
manifests. The weekly run catches release assets that rot between releases.

## Verifying artifacts

Each project ships a cosign-signed (keyless/OIDC) `checksums.txt` and
per-archive SBOMs with every release. Scoop checks each download against the
hash in its manifest. To verify the signature as well, see the
[bronto-cli security policy](https://github.com/bronto-community/bronto-cli/blob/main/SECURITY.md).
